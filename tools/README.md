# Mobility Campaign Reproducibility Tooling

This directory contains standalone, read-only reproducibility scripts for analyzing multi-mobility simulation outputs generated by **The ONE Simulator** and rendering publication figures without IDE or machine-specific paths.

## 1. Requirements

- **Python:** `>= 3.10`
- **Packages:** `numpy`, `scipy` (paired $t$-test, Wilcoxon signed-rank test, exact $t$-quantiles), `matplotlib >= 3.7` (vector `.pdf` and 300-DPI `.png` plotting).
  ```bash
  pip install numpy scipy matplotlib
  ```

## 2. Expected Input Directory Schema

`analyze_mobility_campaign.py` reads ONE simulator output folders without modifying or overwriting any source files:

```text
<reports-dir>/
  env1_vdtn_stress/
    Env1_Stress_<RouterClass>_<Seed>_DtnmaRlMetricsReport.txt
    Env1_Stress_<RouterClass>_<Seed>_MessageStatsReport.txt
  env1_vdtn_benign/
  env2_workingday/
  env3_disaster_relief/
  cross_substrate/
  scale_60/
  scale_126/
  scale_250/
  scale_500/
  campaign.log   # Optional: used only to extract per-run wall-clock runtimes
```

Each report file uses key-value `metric_name: numeric_value` formatting emitted by `src/report/DtnmaRlMetricsReport.java` and stock `MessageStatsReport`.

| Family ID | $m$ | Stage(s) | Target vs. Comparators | Metrics Tested |
|---|---:|---|---|---|
| `F1_Env1_Stress_Core` | `18` | `env1_vdtn_stress` | `M2-Mob` vs. `{M2-SRL, M0e-25, M1-Remote, EnergyOnly, BufferOnly, ReplicaOnly}` | `alive_nodes_end`, `critical_delivery_prob`, `bulk_delivery_prob` |
| `F1b_Env1_Stress_EventC` | `6` | `env1_vdtn_stress` | `M2-Mob` vs. same 6 comparators | `eventC_bulk_deliv` |

## 4. Regenerating All Tables and Figures from Scratch

From any working directory:

```bash
# 1. Aggregate per-seed reports and run Holm-Bonferroni paired tests
python /path/to/ADTNM/tools/analyze_mobility_campaign.py \
    --reports-dir /path/to/the-one/reports/mobility_suite \
    --out-dir ./repro_outputs

# 2. Render all 4 publication figures (vector .pdf + 300-DPI .png)
python /path/to/ADTNM/tools/plot_mobility_figures.py \
    --summary-json ./repro_outputs/summary_stats.json \
    --out-dir ./repro_figures
```

Outputs created in `--out-dir`:
- `per_seed_metrics.csv`: Complete per-run table including source rejections, buffer-eviction losses (`unique_critical_lost`), per-copy TTL expirations, and end-of-run undelivered counts.
- `paired_families.csv`: All 112 predeclared paired comparisons with 95% CIs, effect sizes, and Holm-adjusted $p$-values.
- `summary_stats.json`: Full structured statistics consumed by `plot_mobility_figures.py`.
- `tables_summary.md`: Human-readable Markdown tables.
- `fig1_env1_tradeoffs.{pdf,png}`, `fig2_scalability.{pdf,png}`, `fig3_cross_substrate_forest.{pdf,png}`, `fig4_resource_overhead.{pdf,png}`.
